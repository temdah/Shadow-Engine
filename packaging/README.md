# Shadow Engine

## Requirements

Watch Dogs (2014) and a complete NexusTools 1.1.12-or-newer installation.

## How to install

Close the game. Extract this archive into the Watch Dogs installation folder
and merge the included `bin` folder. Confirm that
`Watch_Dogs\bin\ShadowEnginePatch.asi` exists, then launch normally.

## What it does

Expands and stabilizes the native shadow pipeline so compatible lighting mods
can retain more dynamic and world shadows across all five supported PC builds.
