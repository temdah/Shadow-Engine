# Shadow Engine

Shadow Engine expands dynamic shadow support in Watch Dogs (2014) for Windows PC,
allowing compatible lighting mods to use more shadow-casting lights.

## Installation

1. Install [NexusTools](https://www.nexusmods.com/watchdogs/mods/491) and its requirements.
2. Close the game.
3. Extract this ZIP into your Watch Dogs installation folder, merging the `bin` folder.
4. Confirm `ShadowEnginePatch.asi` is inside the game's `bin` folder, then launch normally.

## Optional diagnostic and toggle tool

Import the separate `ShadowEngine-Tools` ZIP through NexusTools. It adds shadow
settings, a traffic-spawning toggle and one **Create support report** button that
runs the diagnostic stages automatically and saves a ZIP in the game's `bin` folder.
